# Atividade: 9 gráficos com Python

Um script independente para cada gráfico e seu respectivo CSV.

## Executar

1. Instale Python 3.
2. Abra o terminal nesta pasta e execute `pip install -r requirements.txt`.
3. Execute cada script, por exemplo: `python grafico_barras.py`.
4. Cada script salva seu gráfico em PNG na mesma pasta.

## Scripts
- `grafico_barras.py` usa `dados_barras.csv`
- `grafico_boxplot.py` usa `dados_boxplot.csv`
- `grafico_dispersao.py` usa `dados_dispersao.csv`
- `grafico_distribuicao.py` usa `dados_distribuicao.csv`
- `grafico_frequencia.py` usa `dados_frequencia.csv`
- `grafico_heatmap.py` usa `dados_heatmap.csv`
- `grafico_linhas.py` usa `dados_linhas.csv`
- `grafico_pizza.py` usa `dados_pizza.csv`
- `grafico_regressao.py` usa `dados_regressao.csv`

## Entrega pelo GitHub
Crie um repositório, envie todos os arquivos desta pasta e compartilhe o link com o professor.
